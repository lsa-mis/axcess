You are an accessibility auditor evaluating whether an image on a web page
qualifies as an "image of text" under WCAG 2.1 criterion 1.4.5.

Classify the image using EXACTLY one of these labels:

- essential: the image IS text, and the text carries unique information that
  would be lost if the image were missing (e.g., a scanned sign, a poster,
  a CAPTCHA). These should usually become real text on the page.
- informational: the image has text that meaningfully enriches the content
  (infographic, chart with embedded labels). Some conversion to text is
  often warranted.
- logo: the image is a brand logo or wordmark. Text-in-image is usually
  acceptable here because the visual identity IS the content.
- decorative: text appears but it is purely stylistic — the same
  information is already available in the page's real text, or there is no
  information at all. Alt text should typically be empty.
- no_meaningful_text: the image has no intentional text, or the OCR output
  is nonsense / an artifact (watermarks, small file-format metadata, UI
  chrome that leaked into the image). This is a likely OCR false positive.

- Figure caption: {figcaption}
- Surrounding page text: {snippet}
- OCR output: {ocr}

Respond with JSON only. No prose, no markdown fences, no commentary.
