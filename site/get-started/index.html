Get started

Your first scan in about ten minutes

Choose how to install, run one small scan, and read your first report. If you are not a developer, the desktop app is the path for you.

Step 1

Choose how to install

Desktop app (recommended)

One macOS app that bundles everything: the workbench, the browser, the two rule engines, and text recognition. No Python, Node, or other developer tools needed.

  • Apple Silicon Macs (M1 and later)
  • Development preview, updated from the project's build system
  • Free; requires a GitHub sign-in to download

Open the desktop builds

On the builds page, open the most recent successful run and download axcess-macos-apple-silicon. Each build is kept for 14 days. The preview is not yet Apple-notarized, so on first launch right-click Axcess and choose Open. An Intel Mac build is not available yet.

Run from source (technical)

For developers and IT staff on macOS, Linux, or Windows with WSL. Needs Python 3.11 or newer, uv, Node.js 22.22 or newer, and Tesseract.

# clone, then from the repo root:
make setup             # Python deps + Chromium
make migrate           # local database
make alfa-install      # optional second engine
make frontend-build    # build the interface
make run               # open http://127.0.0.1:8765/app/

Full instructions, hosting for a small team, and troubleshooting are in the documentation.

Optional AI checks need a separately installed local Ollama service and downloaded models. Skip this at first; every browser-based check runs without it. How the optional AI is kept local.

Step 2

Run a small first scan

Start with a public site you are authorized to test and a low page limit. You will have a report in a few minutes and a feel for the tool.

  1. Open Axcess and choose "Public scan"

    The dashboard has two buttons at the top: Public scan and 2FA / login scan. Choose the public one for now.

  2. Paste the address of one section

    Something like https://www.example.edu/admissions/. The scope preview will show that only pages under /admissions/ will be visited. Leave Crawl the entire host unchecked.

  3. Set "Max pages" to about 25

    The other defaults are conservative and fine. Under Included tests, leave everything on; the browser-based checks do not need any AI.

    Want to see it work? Turn on "Show the scanning browser window" in advanced settings.

  4. Start the scan and watch

    You will see the current page, counts of pages discovered and tested, which checks ran, and an estimated finish time. You can stop at any point.

Step 3

Read your first report

Start at the issue table

Issues are grouped by cause and sorted by impact. Each row tells you what was detected, why it is an issue, the expected fix, and where exactly. Filter by the evidence lane if you want only deterministic failures first.

Open the evidence

Click through to Page Evidence to see the element on the page, the snippet, and any screenshot. For findings revealed by clicking, it says which control revealed them.

Record decisions

Accept, reject as a false positive, mark remediated, or accept the risk, with a short rationale. Decisions are kept with the report and travel into exports.

Check the manual list

The WCAG 2.2 A/AA review matrix shows which criteria still need a person, with the procedure for each. This is the honest half of the report.

Export when ready

Download the Excel workbook or the audit report from the handoff screen. If expert review is unfinished, the export is labelled DRAFT and you are told what is missing.

Rescan later

After fixes land, scan the same address again. The comparison shows what is new, resolved, and still open.

Good to know

Before you scan

Authorization

Only scan sites and accounts you are explicitly permitted to test. Axcess records when robots.txt is ignored, and refuses controls named sign out, delete, or unsubscribe.

One scan at a time

Axcess runs one crawl per app at a time, matching its local single-writer database. Start the next scan when the first finishes.

Time per page

Rendering pages in a real browser and running several checks takes a few seconds per page. Advanced settings let you skip individual checks when speed matters more than coverage, and say what you lose.
