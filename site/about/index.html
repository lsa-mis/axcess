About Axcess

Accessibility evidence you can inspect.

Axcess is a local-first accessibility auditor that explores a scoped web property, records what its detection layers observe, and helps a human decide what to fix. It is built for investigation—not certification.

Why Axcess exists

A single score hides the details that make accessibility work actionable. Axcess keeps the page, selector, browser observation, rule, screenshot, and confidence level connected so reviewers can verify each claim and hand developers a concrete remediation target.

Local by default

Scan evidence lives in local SQLite storage and content-addressed image blobs. Optional model-assisted checks can use a deliberately configured local Ollama service.

Multiple independent signals

DOM rules, keyboard behavior, responsive layout, focus, image analysis, and semantic review remain visibly attributed to the pipeline that produced them.

Built for modern applications

Rendered crawling discovers client-side SPA routes, while controlled click-through exploration records meaningful DOM states that a simple page load would never expose.

Human review stays central

Deterministic failures and judgment-based leads are kept distinct. Axcess reports evidence and limitations; it does not claim legal compliance or complete conformance.

From site to evidence

Every report is scoped to one scan and keeps coverage transparent.

  1. Define the scope. Choose a public or authorized login-protected target, path boundary, crawl depth, and page limit.
  2. Explore routes and states. Render pages in Chromium, follow allowed links and SPA routes, then conservatively operate eligible controls to reveal additional DOM states.
  3. Run detection layers. Apply axe-core and independent browser probes, with optional local AI-assisted analysis for contextual questions.
  4. Review and verify. Group repeated occurrences into issues, inspect the stored evidence, assign remediation work, and rescan to compare changes.
Important: automated and AI-assisted results are evidence for expert review. They do not prove the accessibility of an entire website, WCAG conformance, or legal compliance.

Open source and locally operated

Axcess is MIT licensed. The crawler, evidence store, FastAPI service, React review interface, and export pipeline are developed in the open.
